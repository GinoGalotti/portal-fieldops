The Lab

// ORGANISATION OVERVIEW
// FOUNDING
P.O.R.T.A.L — Origin
Founded less than a decade ago by Dr. Leech — an eminent statistician and epidemiologist whose theories on evolution were, at the time, widely dismissed. The lab spent its first years losing money. Grants dried up. Papers went unread or were ridiculed. Then the breakthroughs started coming. Results that couldn't be replicated by anyone else. Predictions that proved eerily accurate. The lab is now well-funded and carefully mysterious about its methods.
⚠ NOTE: The source of the lab's recent breakthroughs is known only to cleared personnel. If you are reading this, you are cleared. Do not discuss with outside parties.
// AI SYSTEM
CAMPBELL
The lab's pattern-recognition and anomaly-detection system. Continuously cross-references public data feeds against a classified index of supernatural signatures. Generates field reports, threat assessments, and resource recommendations. Its accuracy is, frankly, difficult to explain.
// ACTIVE RESEARCH
Project Veil
The lab's primary long-term research thread. Details are above most field team clearance levels. What is known: certain materials recovered from field operations have the potential to accelerate it significantly. The Director considers it the most important work the lab is doing.
// MISSION
Why We Do This
The lab operates on a founding principle that has never been publicly articulated but is understood by everyone who works here: the supernatural edge we have discovered is to be used in the service of humanity. This is not a tagline. It is, in ways that will become clearer over time, a binding commitment. Field teams are trusted to exercise judgment in the field — but that judgment is always in service of this principle, even when the directive is uncomfortable.

How to Host This Site

// KEEPER INSTRUCTIONS — DELETE THIS SECTION BEFORE SHARING

GitHub Pages is free, takes 5 minutes, and gives you a real shareable URL. No coding required after setup.

01
Create a free GitHub account

Go to github.com and sign up. It's free. You only need the basic account.

02
Create a new repository

Click the + button → "New repository." Name it something like portal-fieldops. Set it to Public. Check "Add a README file." Click "Create repository."

03
Upload this HTML file

In your new repository, click "Add file" → "Upload files." Drag this HTML file in. Rename it to exactly index.html before uploading — this is important. Commit the upload.

04
Enable GitHub Pages

Go to your repository → "Settings" → "Pages" (left sidebar). Under "Source," select main branch and / (root) folder. Click Save. GitHub will show you your URL — something like yourusername.github.io/portal-fieldops. It takes about 60 seconds to go live.

05
Updating the site in future

When you want to update — after a session, adding a new monster, etc. — paste the HTML into Claude to make changes, download the new file, go back to your GitHub repository, click on index.html, then the pencil "Edit" icon, paste the new content, and commit. The site updates within 60 seconds. No other tools needed.

06
Delete this section before going live

Remove everything between the <!-- HOSTING GUIDE --> comments in the HTML before you upload to GitHub. You don't want your players reading the setup instructions. Ask Claude to remove it for you if needed.
